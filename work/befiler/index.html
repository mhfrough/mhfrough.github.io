More than income tax

Each service has its own page on befiler.com, its own flow in the dashboard and its own queue in the staff portal.

Sales tax

Registration with FBR or a provincial authority, monthly returns with sales and purchase reconciliation, nil returns, and help with notices, appeals and hearings. Each request becomes a case in the sales tax queue.

USA filing and company formation

An LLC or corporation in any state, a complete package with EIN and a US bank account, ITIN for non US citizens, federal and state tax filing, and US trademarks. Consultant and LLC manager portals run these cases.

Three ways in

  • HBL, Allied, MCB, UBL, Abhi

    Encrypted handoff

    The bank app opens the widget with an encrypted payload. The widget trades it for a session, then sends new customers to a short profile and returning ones to their dashboard.

  • Bank Alfalah

    Issued token

    The bank issues a token before it opens the widget. The widget validates it and starts the session, with no second sign-in.

  • Easypaisa

    Wallet bridge

    The mini-app asks the wallet’s JavaScript bridge for an auth code, with the customer’s consent to share name, phone and CNIC. Bridge callbacks run inside Angular, so the screen updates.

  • Work queues

  • Assignment and SLAs

    Cases and leads go to the right person. A service builder sets each service’s fields, documents, pricing, triggers and escalation.

  • Leads and sales

    Leads, callbacks and a calendar with notes. Agent targets and commission on Highcharts dashboards.

  • Payments and refunds

    Card, RAAST, bank transfer and cash, FBR challans, and refunds that pass consultant, supervisor, admin and finance.

    Each permission is an action on a resource. A structural directive shows only what a user may do, and sessions and activity are logged.

Decisions and what I’d change

Years on one product teach you which shortcuts age well.

  1. 01

    A build per bank

    Each bank got its own clone of the widget template: colours, handoff and payment bridge. One bank’s release never waited on another’s. The cost is that a fix lands in every build, so the next step is one widget with partner config at runtime.

  2. 02

    Payment stays with the host

    Inside a bank app the widget never sees card details. Some banks debit the account after an OTP in the widget; others take payment in their own app and hand the result back, and the widget checks until it settles.

  3. 03

    A flow built from data

    The order of steps is computed from what the customer earns. Pick salary and rent, and only those schedules appear in the sidebar.

  4. 04

    Permissions as data

    Staff roles change often. A permission is an action on a resource, stored per user, and the UI reads that list, so a new role needs no release.

  5. 05

    Urdu, right to left

    The dashboard and newer widgets switch to Urdu with ngx-translate, flip the layout to RTL, and tell the API which language to answer in.

  6. 06

    Static where it can be

    befiler.com stays PHP and vanilla JS with a Gulp build: fast first paint for search, calculators and status checkers, the blog pulled from WordPress.
