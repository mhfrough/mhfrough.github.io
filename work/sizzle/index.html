The project page

Dressed as a film release: soft black, one bronze accent, poster capitals over a book serif. A cutting room that recuts a reel as you type, a production schedule, and a three.js cinema that screens the trailer. Captured from the live site.

The same page in one column. The install line sits under the headline, and the cutting room keeps its reel preview, transport and timeline.

  • The cinema loads only when you scroll to it; every control in it is also a plain button
  • Fonts and three.js are self-hosted, so nothing loads from a CDN

Under the hood

Plain files an agent can read: Markdown for the method, one JavaScript renderer, Python for sound and encoding.

  • 01

    A fake clock, frame by frame

    render.js drives Chromium through Playwright with a faked clock, so timers and animation frames fire at exact reel times, and every CSS animation is paused and seeked to the frame before each screenshot.

  • 02

    Every time in one place

    A reel page keeps all its timing in one CUES object, and elements hang off it with data-in and data-out. A retime is one edit and a re-render; a new track only needs the mix step again.

  • 03

    The drop on the reveal

    music_sync.py finds a track’s tempo and its strongest hits, then scores the offset that lands each hit on your cue: a quieter build before it, a steady body after, and enough track to last.

  • 04

    A mix without ffmpeg

    mux.py encodes H.264 High at crf 16 through PyAV, ducks the music under sound effects and voice, normalises to -14 LUFS with BS.1770-4 gating, and limits the true peak to -1 dBTP.

  • 05

    No two reels alike

    fingerprint.py keeps a history of every reel across all projects. A direction too close to a recent reel fails, and so do rendered stills that look like an earlier reel’s.

  • 06

    Sound from scratch

    synth.py makes 20 kinds of sound effect in 6 kit palettes, and music beds in 9 genres whose downbeat lands on the drop. Pure synthesis: no samples, no licence, no download.

Decisions

Each one keeps a reel true to the product and cheap to change.

  1. 01

    A web page, not a video editor

    A reel is an HTML page with one timeline. Agents already write HTML, it previews in any browser, and the renderer steps it frame-exact. No editing app in the loop.

  2. 02

    The real interface, not screenshots

    The reel links the product’s own stylesheet or drives its own renderer with invented data. Text stays sharp at 4K, everything can move, and no real names or files end up in the video.

  3. 03

    Approval before rendering

    Rework after a 4K render is expensive, so the agent stops for the script and again for the picture. Ask for changes and it goes back to the build, not to the start.

  4. 04

    One plain folder, any agent

    SKILL.md follows the open Agent Skills format: YAML front matter, then Markdown. Claude Code, Codex, Cursor, Gemini CLI and OpenCode load it as a skill; any other agent reads it as instructions.

Install

One line for any agent that reads skills, or an installer that puts it where Claude Code or Cursor looks. Then ask for a reel.

$npx skills add mhfrough/sizzle

Adds it to Claude Code, Codex, Gemini CLI, OpenCode and the other agents the skills tool supports.

Then say

“make a promo reel for this app”

Once per machine

npm i -D playwright && npx playwright install chromium
pip install -r skills/sizzle/tools/requirements.txt

Node 18 or newer with Playwright, Python 3.10 or newer. No ffmpeg, no editing app.

Where it stops

From SKILL.md and the README. A tool that speaks for your product should be careful about what it puts on screen.

Works

  • Any agent that can read files, write files and run shell commands
  • Reels at 9:16, 4:5, 1:1 or 16:9, about 6 to 60 seconds, the length set by the concept
  • A free track or a bed made on your machine, with sound effects on the reel’s own moments
  • Windows, macOS and Linux, with Node 18+, Playwright and Python 3.10+

Does not, by design

  • Render 4K frames before you approve the script and the picture
  • Download a track without naming the file, the host and its size, and asking first
  • Put real names, emails, devices or tokens on screen; demo data is invented
  • Make a claim the product cannot back: every line on screen gets a source in the claims check
  • Repeat a recent reel: a concept, font, opening, signature or music genre from the last three fails the check

The stack

No build step, no ffmpeg, no editing app. The tools need Node and Python once per machine.

  • The skill

    The method as Markdown with its gates, plus references, a cookbook of worked techniques and a bare reel engine with no look of its own.

    • Markdown
    • Agent Skills format
    • HTML and CSS

  • Render

    One Playwright script with a fake clock: any canvas size, frames at twice the CSS size, stills and a contact sheet for checking.

    • Node.js
    • JavaScript
    • Playwright

  • Sound and encode

    PyAV with its bundled libx264 for the MP4, NumPy and SciPy for analysis and synthesis, OpenCV and Pillow for stills.

    • Python
    • PyAV
    • NumPy and SciPy

  • The page

    Static files on GitHub Pages with no build step. three.js, Bebas Neue and EB Garamond are vendored, so nothing loads from a CDN.

    • JavaScript
    • three.js
    • GitHub Pages
