Scrawl.Felt-tip diagrams on dotted paper.

A sketchbook I wrote for the browser in plain JavaScript: boxes, circles and arrows drawn as single marker strokes, fills printed like a risograph, and every page saved on your own device. Draw on the page here; the real one is a click away.

The real sketchbook

Screenshots of the public app, served from the repo as it is, with sample drawings written into its own storage.

One stroke per edge

Scrawl does not trace a shape and then roughen it. Each edge is one bowed marker stroke, and the seed stored on the shape decides every wobble.

  1. 01

    A bowed stroke, not a straight line

    Each side is one cubic curve: both ends nudged a little and the middle bowed off the line, further on longer sides and wilder hands, up to a cap.

  2. 02

    Corners that cross

    Box sides run past each other at the corners, like a quick architect’s sketch. Diamonds overshoot less than half as much.

  3. 03

    Loops that carry on

    Circles and rounded boxes are drawn in one go through jittered points, and the pen keeps going one or two points past where it started.

  4. 04

    One seed, the same wobble

    Every element carries a seed for a small random generator, so it looks the same on every redraw, in every export and on every device.

// scene.js: one felt-tip stroke, with optional overshoot
function markerLine(p, x1, y1, x2, y2, rough, rand, over = 0) {
  const len = Math.hypot(x2 - x1, y2 - y1) || 1
  const j = () => (rand() - 0.5) * 2 * Math.min(1.2 * rough, len / 12)
  const bow = (rand() - 0.5) * Math.min(len / 24, 7) * rough
  // ...start and end nudged by j(), the middle bowed by bow
  p.C(cx1 + nx * bow, cy1 + ny * bow,
      cx2 + nx * bow * 0.8, cy2 + ny * bow * 0.8,
      x2 + j(), y2 + j())
}

Fills that look printed

Three fill styles borrowed from print. Change the pen and the numbers move with it: they are the ones scene.js uses.

  • Offset prints the tint 4 px plus one and a half pen widths off the outline, so it peeks out like a risograph out of register.
  • Solid uses the same outline with no shift. Dots lays a halftone screen in rows 0.87 steps apart, every other row offset by half a step.
  • The step grows with large shapes, so a big box never turns into thousands of dots.

The rest of the pencil case

Twelve tools, each on one key. The ones that make it feel like a sketchbook rather than a diagram editor:

  • Pen

    A filled outline, not a stroked line: it swells where you draw slowly and tapers over the first and last five points.

  • Highlighter

    A broad, square-ended stroke at 38% that multiplies on light paper and screens on dark, so it tints what is under it.

  • Lettering

    Hand (Shantell Sans) or print (Bricolage Grotesque) in four sizes. Double-click anywhere to write, or on a shape to label it.

  • Taped pictures

    Drop, paste or pick a photo and a strip of torn masking tape holds it on, with seeded ragged edges and a slight tilt.

  • Keep the tool

    The tool you pick stays on, so you can draw line after line. Press Q to go back to Select after each shape instead.

  • Phones

    At 760 px and below the tools move to a bar along the bottom, and two fingers pinch to zoom and move around the page.

Dark paper, same drawing

A black marker would vanish on dark paper. Scrawl keeps each colour’s hue and saturation and flips its lightness, so a drawing reads the same either way.

Local first, no account

There is no server. Every page lives in the browser that drew it, and a file is one click away when it needs to travel.

  1. Autosave

    localStorage
    • Saves 400 ms after the last change, and again when the tab is hidden or closed
    • One key per drawing, plus an index, the open page and your preferences
    • A full browser shows “Not saved: storage full” and points to Save to file

  2. Pictures

    IndexedDB
    • Photos go to IndexedDB, which has room for them; drawings keep only an id
    • Anything over 2400 px or 3 MB is redrawn at 2400 px at most and stored as WebP, or JPEG where WebP is missing
    • Pictures no drawing uses any more are cleared a few seconds after start

  3. Files

    .scrawl
    • Plain JSON: type, version, name, elements, and pictures as data URLs
    • Opening one checks every field: known types, hex colours, clamped numbers, image data only
    • Drop a .scrawl file anywhere on the page to open it

  4. Exports

    PNG · SVG
    • PNG at 1x, 2x or 3x, or straight to the clipboard
    • SVG from the same paths, with the fonts linked so it renders anywhere
    • With or without paper, light or dark, all or just the selection

Small things that keep it quick

Plain JavaScript still needs care once a page holds a few hundred marker strokes.

  • 01

    Geometry cached per version

    Each element’s paths are built once and kept until the element changes; a second cache holds the Path2D objects.

  • 02

    Only what is on screen

    The editor skips anything outside the view, and draws the dotted paper in screen space so it stays crisp at any zoom.

  • 03

    Undo as snapshots

    Up to 150 steps, each a snapshot of the page, committed at the end of a gesture rather than on every pointer move.

  • 04

    Other tabs stay in step

    A storage event reloads the open drawing when another tab saves it, unless you are mid-drag or typing.

  • 05

    Validation at every door

    Storage, files and the clipboard all pass through one sanitiser: unknown types are dropped, numbers clamped, text and points capped.

  • 06

    Thumbnails from the SVG renderer

    My drawings shows each page as an SVG data URL from the export code, so thumbnails cost no extra drawing code.

What it does, and its limits

Straight from the README. Local first is the point, and it comes with trade-offs.

Works today

  • Boxes, circles, diamonds, arrows and lines in three hands
  • Offset, Solid and Dots fills; pen, highlighter, text and taped pictures
  • Select, multi-select, move, resize, Alt-drag to copy, layer order, snap to the dots
  • Autosave, any number of pages, .scrawl files, PNG and SVG export
  • Dotted, ruled or plain paper; light, dark or automatic theme; phones

Limits

  • Drawings live in this browser only. Clearing site data deletes them, so save to a file to keep one.
  • localStorage holds roughly 5 MB per site: thousands of shapes, not unlimited. Scrawl warns when it is full.
  • Pictures sit in IndexedDB on this device. Saving to a file embeds them, so files with photos can be large.
