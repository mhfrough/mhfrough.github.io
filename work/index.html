@mhfrough/star-rating

A tiny, dependency-free function that turns a number from 0 to 5 into a star string, with half stars. Published on npm in July 2025.

See it on GitHub(opens in a new tab) See it on npm(opens in a new tab)

Try it

★★★⯪☆

rating(3.5) // "★★★⯪☆"

Any number from 0 to 5, decimals allowed. Half a star shows from .5 up.
