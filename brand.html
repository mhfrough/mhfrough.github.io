The hamza mark

The mark is the Arabic letter hamza (ء), the first letter of Hamza, drawn from two primitives on a 48 unit grid. It always sits on the brand tile: a circle filled with --cta, inside a pill in the nav and footer.

Two inks, many greys

The palette is monochrome on purpose. The accent is the ink itself, so anything that needs attention inverts: CTAs, pressed chips and the brand tile use a light fill with dark text.

When to use mono

  • Commands and code: the .cmd bar, .code blocks, inline code.
  • Metadata: dates, versions, durations, file names, the handle.
  • Numbers that line up: counts, timestamps, ratios.
  • Small captions under specimens and reels.
  • Never for headlines, buttons or running prose.

Motion on content

Motion follows reading order: the headline rises, the rest fades up, sections reveal as they arrive. Transform and opacity only.

Live demos

Each demo uses the global classes, so reduced motion behaves here exactly as it does on every page.

Rules

  • Motion belongs to content: headlines, cards, sections. Never to the pointer.
  • No custom cursor. No magnetic buttons. No animated link underlines.
  • No big footer CTA text.
  • Transform and opacity only. Looping animations pause off screen.
  • Every animation sits behind prefers-reduced-motion: no-preference.
  • One marquee per page, at most.

Usage

import { NgIcon, provideIcons } from '@ng-icons/core';
import { phosphorArrowRight } from '@ng-icons/phosphor-icons/regular';

@Component({
  imports: [NgIcon],
  viewProviders: [provideIcons({ phosphorArrowRight })],
  template: `<a class="btn btn-solid" routerLink="/work">
    View work<ng-icon name="phosphorArrowRight" aria-hidden="true" />
  </a>`,
})
  • Decorative icons get aria-hidden="true". The button or link carries the name.
  • Icon-only buttons need aria-label.
  • Icons take currentColor; never color them separately.
  • UI icons are Phosphor only. Custom drawing is limited to the hamza mark and portfolio artwork such as the weather icon set on /work, which is never used as UI.

Plain, exact, short

Copy is written like a commit message from someone senior: facts first, no hype, nothing the CV cannot back.

House rules

Checked before anything ships.

No em or en dashes
Use a comma, a colon or a full stop. U+2014 and U+2013 never ship.
No filler verbs
Say what it does. Words like elevate, seamless and unleash are out.
Facts only
Since 2020, 7+ years, 30+ products, 6 banking apps, 4 Angular apps. Numbers come from the CV.
Never name employers
Describe products by domain: a tax-filing platform, a fleet SaaS. No company or bank names.
English only
One language, sentence case, no exclamation marks.

Accessible by default

WCAG 2.1 AA is the floor, checked with axe in Playwright on every page. The system makes the accessible choice the easy one.

  • Contrast

    Text clears 4.5:1 on every surface; ink and ink-2 clear 7:1. --faint and lines are never text.

  • Targets

    Buttons 44px, inputs 46px, icon and small buttons 40px. Chips and tabs are the floor at 32px.

  • Focus

    2px ink outline, 3px offset, following the pill shape. Never removed.

  • Landmarks

    Skip link, header nav "Primary", one main, footer. One h1, headings in order.

  • Reduced motion

    prefers-reduced-motion drops every transition and loop to its end state.

  • Reduced transparency

    The glass nav becomes solid --surface when transparency is reduced.
